# Java Debug Lab

A collection of Java programs containing **intentional bugs** for students to find and fix. Each file focuses on a specific topic in Java GUI programming.

The goal is simple: **read the code, find the errors, fix them, and make it run correctly.**

---

## Purpose

This lab is designed for students learning Java Swing and GUI programming. Instead of writing code from scratch, students practice **reading, understanding, and debugging** code — a skill that is just as important as writing it.

Each exercise file has one or more deliberate errors such as:

- Typos in method or class names
- Wrong method signatures
- Missing imports
- Incorrect listener types
- Wrong constructor arguments
- Logic errors (e.g. `==` instead of `.equals()`)
- Missing method implementations

---

## Who This Is For

- BCA / CSIT students studying **Advanced Java Programming**
- Anyone learning **Java Swing**, event handling, and GUI design
- Self-learners who want hands-on debugging practice
